ASA Events — Admin

Internal tools for the WGITA/KSC 2026 registration system. Not linked from the public site.

Admin tools

Need the admin token — manage invitations, registrations, reminders and the audit trail.

Admin token Invitation Codes Generate and track the codes SAIs use to unlock the registration form. Admin token Registrations & Reports Approve or decline, set protocol tier, edit anyone's form, download files, and merge duplicate organisation/hotel spellings. Admin token Reminders Email participants about missing itinerary, hotel, presentation or accompanying-person details — preview before sending. Admin token Audit Trail Every registration, edit, status change, invitation and error — searchable, with a Telegram alert on the events that matter.

Reports

Accept the admin token or the separate, narrower report/viewer token — safe to share with people who shouldn't see the tools above.

Admin or report token Full Report Every confirmed participant's complete submitted data, one card each, plus a compact summary table grouped by event. Admin or report token Leadership Dashboard KPI figures and rows-by-columns tables — by event, tier, role, organisation, hotel and more. Admin or report token Logistics Reports Grouped by arrival date, departure date, hotel, passport status, accompanying persons, speakers and attachments.
Each page keeps its own token in that browser tab only (sessionStorage) and never shares it with the others.
