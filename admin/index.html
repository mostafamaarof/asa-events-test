Access token

Works for the admin token, the shared viewer token, or a named token created on the Access Tokens page. Kept only in this browser tab (sessionStorage).
Each page keeps its own token in that browser tab only (sessionStorage) and never shares it with the others. This hub only ever shows the pages your token can actually open — every page enforces that itself as well.
